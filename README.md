# Lampy – Illuminate Your Space

Lampy is a modern lighting website designed to showcase stylish and elegant lamps for home interiors.

## Features

- Modern and responsive website design
- Home page with hero section
- Collections page
- Best Sellers page
- About Us page
- Product Details page
- Wishlist page
- Shopping Cart page
- Navigation between pages
- Product images and categorized content
- Clean and minimal lighting-themed UI

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Git & GitHub
- GitHub Pages
